# Meta-T Duration Pilot v0.3.1

Built from v0.3. Changes only timing and condition selection.

- Practice: 1 minute.
- Five conditions, 2 minutes each.
- Conditions: EEG L0 (800 ms), L4 (467 ms), L6 (300 ms), L7 (217 ms), L9 (100 ms) per gravity drop.
- After every condition: the same challenge and frustration 1–7 ratings as v0.3.
- Gameplay mechanics, consent flow, telemetry, and Google Drive checkpointing remain unchanged.
- Gameplay duration: 11 minutes, excluding questionnaires and transitions.

Note: the separately deployed Google Apps Script backend may still record study_version 0.2 in session.json. The front-end experiment version is 0.3.1-duration-pilot.
